# Changelog

Все заметные изменения этого проекта документируются в данном файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект следует [Semantic Versioning](https://semver.org/lang/ru/).

Версия приложения берётся из `version.txt` (MAJOR.MINOR.PATCH); номер сборки —
количество коммитов на момент сборки. Полная строка версии (ProductVersion в
свойствах exe, например `1.0.0.123 (a1b2c3d, 2026-11-03, Debug)`) содержит
номер сборки, короткий хэш коммита, дату и конфигурацию — этого достаточно,
чтобы по баг-репорту однозначно найти коммит:

    git rev-list HEAD | Select-Object -Last <build> | Select-Object -First 1

Релизы помечаются тегами вида `vX.Y.Z`.

## [1.0.0] - 2026-11-03

Первый выпуск.

### Added

- Хранение SSH-сниппетов, цепочек, тегов и категорий в локальной базе SQLite
  с историей изменений сниппетов.
- Поиск по сниппетам: быстрый поиск и язык запросов.
- Вставка сниппетов и макросов в терминалы (MobaXterm и другие) через окно
  выбора терминала с живым превью, включая свёрнутые окна.
- Экспорт и импорт сниппетов в Markdown.
- Инструменты: генератор паролей, конструктор cron-выражений, конвертер
  epoch-времени, сетевые калькуляторы, chmod.
- Темы оформления, русский и английский интерфейс, глобальные горячие клавиши.
